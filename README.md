# ComicVerse

Este é meu projeto para a disciplina de Programação Web II. O ComicVerse é uma biblioteca de HQs e mangás, desenvolvida por Davi Antônio Galeano Lazzaroto.

## O que já funciona

O projeto tem telas de início, catálogo, detalhes de uma obra, administração, novo cadastro e sobre. O menu permite navegar entre início, catálogo, sobre e administração. O catálogo, os detalhes e o cadastro ainda são estruturas de interface, sem obras ou dados reais.

## Próximas etapas

Nas próximas etapas da disciplina, pretendo integrar a API e o Firebase para carregar e administrar os dados das obras.

## Como executar

Instale as dependências e inicie o servidor:

```bash
npm install
npm start
```

Depois, acesse [http://localhost:4200](http://localhost:4200).
